## 第 1 部分：侦察偏移

### 原则

`target$x/y` 从此表示**侦察上报坐标**（玩家可见的一切：简报、地图、`诸元 target`、
`任务` 都用它）；新增 `target$truth_x/truth_y` 表示**真实坐标**，只有三处"游戏裁判"逻辑读它。
无 `truth_` 字段的目标（教程关、历史场景）按 `truth %||% x` 回退到自身，行为与现在完全一致。

### 改动点

1. **config.R**：新增常量
   ```r
   RECON_ERROR_M <- 15   # 侦察误差上限 (m)；随机战役目标上报坐标 = 真值 + 随机偏移(5~15m)
   ```
2. **mission.R `new_mission` 普通分支**：抽完 `(tx, ty)` 后
   ```r
   err_m <- runif(1, 5, RECON_ERROR_M); err_az <- runif(1, 0, 2 * pi)
   rx <- tx + err_m * cos(err_az) / 1000;  ry <- ty + err_m * sin(err_az) / 1000
   ```
   `target = list(x=rx, y=ry, truth_x=tx, truth_y=ty, label=..., radius=...)`。
   简报打印照旧用 `x/y`（即上报坐标）。
3. **读真值的三处**（统一 `t$truth_x %||% t$x` 写法；`%||%` 已在 map.R 定义）：
   - `mission.R observer_report`：`r_tgt`/`az_tgt` 基于真值（观察员在真实目标处观察）
   - `mission.R check_destroyed`：弹着到真值距离 ≤ radius 判摧毁
   - `game.R` `修正` 命令：`r_tgt` 用真值（偏差是相对真值报的）
4. **不改**：`draw_state`/`map.R`（画上报坐标，正是玩家所知）、`fdc.R`（算上报坐标，
   情报误差自然进入装订）、教程关 `start_tutorial`、场景分支 `new_mission`。
5. **配套提示（自审补充）**：
   - `new_mission` 随机分支简报末尾加一行：`注: 侦察坐标存在 ±15m 内误差，试射修正可消除。`
   - README.md「特色」任务战役条目补一句侦察误差说明（防文档漂移）

### 玩家体验

简报给 (10.02, 12.47)，实际真值可能在 5~15 m 外任意方向。首试射按计算器装订打向上报点，
观察员报出相对真值的小偏差（与散布偏差混在一起），照常 `修正` 即收敛——
与真实炮兵"试射修正同时消化侦察误差与散布"一致。

### 测试（追加到 tests/test_game.R）

1. 固定 seed 开战役 → `mission$target` 含 `truth_x`，且上报点到真值距离 ∈ [5, 15.001] m
2. 教程关目标无 `truth_x`；列宁格勒场景目标无 `truth_x`
3. 向 `state$shots` 手工塞入真值坐标的弹着 → `check_destroyed` 判定摧毁
   （证明判定读真值而非上报坐标）
4. 回归：现有全部测试继续通过（`playthrough.R` 三模式照常打通，即端到端证明
   试射修正能消化侦察误差）

## 第 2 部分：TUTORIAL.md 重写

### 大纲（9 节）

1. **这是什么游戏**：一段话 + 胜利条件（最少弹药摧毁目标、S~C 评级）
2. **运行**：RStudio / 命令行两种方式（保留现有内容，含全部启动参数）
3. **5 分钟打出发弹**：教程关手把手，配真实控制台输出摘录
4. **原理（直观+公式）**：
   - 密位：6000 密位圆；推导 1 密位 ≈ 1 m @ 1 km；修正公式 `密位 = 偏差m ÷ 射程km`
   - 方位/高低/装药三要素；最大射程角 ≈45°（真空 `R = v²·sin2θ/g`），超过进高射界
   - 空气阻力：平方律 `F = k·v²`，游戏按历史最大射程反推阻力系数（一句话讲校准）；
     RK4 = "把飞行切成 0.2s 小步、每步四点取样求平均"的人话解释
   - 散布：概率误差 PE（50% 弹着落在 ±PE 内）、`σ = PE/0.6745`；D-20@10km ±30~55 m
     → 为什么试射必不可少
   - 风：`漂移 ≈ 风速 × 飞行时间 × 0.55`
   - 高差：`site = atan(Δh / R)`
   - 侦察误差（新功能）：上报坐标有 5~15 m 误差，试射修正自然消化
5. **射表与数据**：5 门炮"装药 × 射角(每 100 密位) → 射程"压缩表 + 最大射程/峰值射角；
   完整内插算例；由新脚本 `tools/gen_manual_tables.R` 从游戏内 `build_range_table`
   生成 Markdown 粘入，保证与游戏一致
6. **完整对局实录**：标准模式一个任务的全部命令与输出，逐条解说
7. **速查**：命令表 / 三模式 / 目标类型 / 评分规则（保留现有精华）
8. **战术技巧**（保留现有 + 侦察误差相关提示）
9. **真实地形 / 故障排查**（保留现有）

### 新文件

  `build_range_table` → 输出 Markdown 表格到 stdout（人工粘入 TUTORIAL.md；
