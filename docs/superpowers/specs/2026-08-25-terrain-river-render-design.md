# 设计文档：地形重生成——自然河流 + 高对比渲染

日期：2026-08-25
状态：三节设计已经用户逐节确认批准
关联：实施顺序为 本规格 → 侦察偏移+TUTORIAL.md 重写（见 2026-08-25-recon-offset-tutorial-design.md）

## 背景与病灶

用户反馈：地形"糊"、颜色对比度低、河流像随手画的曲线叠在地形上。根因：

1. `draw_map()` 默认 `shade = FALSE`，游戏内渲染的是无山体阴影的平色图
2. 调色板全是中间调（相近的绿/土黄），阴影系数 0.55+0.45·hs 温和，等高线 35% 透明度细线
3. 河流是一条正弦曲线 `lines()` 叠画；挖谷仅 45m 深 / 0.45km 宽，几乎不可见；河与地形互不关联

## 已确认决策

| 决策点 | 结论 |
|---|---|
| 水系形态 | 单条蜿蜒主河（顺坡游走+动量），不做支流树杈 |
| 清晰度 | 全开：默认山体阴影+强阴影+高对比调色板+50m 分辨率+等高线加强 |
| 生成耗时 | 2~4s 可接受（目标实测 1~3s） |
| 实施顺序 | 地形优先，之后侦察偏移+教程 |

## 第 1 节：地形与河流生成（map.R `gen_terrain_procedural` 重写）

### 河流生成（先有谷，后有水）

1. **起点**：地图西侧 15% 列中随机取 24 个格点，取最高者为河源（每局随 seed 不同）
2. **游走**：当前格 8 邻域逐格评分，取最低分者走一步：
   `score = elev[邻格] + W_meander·(1−cos(邻向, 上一步方向)) − W_east·Δx(格数) + 抖动`
   起始权重 `W_meander=15m、W_east=0.2m/格、抖动±3m`（单位都是高程米；以渲染效果调参）
   ——总体必然向低处流（高程主导），动量项产生自然蛇形，东向引力保证通常能从西边界流到东边界
3. **终点**：到达地图任意边界 = 入海口；**遇坑（8 邻域全更高）强行穿越最多 5 步**，
   仍出不去则就地终止并把该处 water_mask 膨胀 ~3 格成小湖
4. **挖谷**：局部窗口法（计划阶段简化，效果等同距离变换且更快）——谷贡献在半宽
   W 之外恒为 0，故逐河点只在 (2W/res)² 邻域内更新 `carve = D(t)·max(0,1−d/W(t))^1.5`
   并取 pmax；沿河按路径进度 t∈[0,1] 线性取谷深 D(t)=15→60 m、谷半宽 W(t)=80→250 m
5. **水面**：`d < 0.4·W(t)` 的格点写入 `water_mask`（渲染为真实蓝色水面）；
   `map$river` 折线仅保留用于"河"字标注与弹道侧视图，并带 `draw = FALSE` 标记——
   `draw_map` 对**未带该标记**的河仍画蓝线（列宁格勒 DEM 图的涅瓦河 150m 分辨率
   解不出河道，全靠标注线表示，必须保留）；程序生成河有真水面，不再叠画蓝线
6. **分辨率**：`MAP_DEFAULT$res_m` 100→50（20km 图 = 400×400 格）；
   `elev_lo` 60→80 m，保证最深河床 ≥20 m 不破调色板下限
7. 兼容：`water_mask` 为 map 新可选字段，`terrain_rgb`/`draw_map` 等高线/`snap_to_land`
   均已支持该字段（DEM 路径现成）；教程关、列宁格勒场景（真实 DEM）行为不变，
   程序生成只是场景的无缓存回退

### 已知取舍

- 道路（南北向直线）可能跨河无桥——纯示意装饰，不处理
- 单主河无支流；湖泊仅"遇坑"意外产物，不做湖泊链

## 第 2 节：渲染与对比度（map.R）

1. `draw_map(shade = TRUE)` 改默认——游戏内启用山体阴影
2. 阴影强度 `0.55+0.45·hs` → `0.42+0.58·hs`
3. `terrain_palette` 换高对比 11 档（深→高）：
   `#173d1c #28611f #3f7d2a #63973a #8fae4a #b9bd60 #c6a35e #a97f4f #8d7a63 #b5b0a8 #efeeea`
   （深绿谷地→草地→干草原→农田土黄→棕→灰棕→岩屑灰→近白峰线）；`terrain_palette2` 保留供对比
4. 等高线 `alpha.f` 0.35→0.5、`lwd` 0.6→0.7
5. 水色 `(0.42,0.66,0.85)` → `(0.28,0.52,0.80)`（加深，河谷在阴影下自然凹陷）
6. DEM 真实地图走同一渲染路径，自动受益；`interpolate=TRUE` 保留（50m 网格下平滑无害）
